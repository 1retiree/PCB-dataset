**1. 背景介紹**

印刷电路板（PCB）在制造过程中经常会出现多种表面缺陷，这些缺陷不仅影响外观，还可能对电路板的性能造成损害。因此，检测PCB表面缺陷对于品质管控至关重要。
传统的缺陷检测方式主要依赖人工视觉检查，存在主观性强、效率低下等问题。深度学习技术的快速发展提供了更高效且精准的缺陷检测方案，然而，这需要大量且多样的数据集来进行模型训练。
该研究建立了一个包含9种PCB表面缺陷类别的数据集（PCB4ZSAD），这些缺陷根据其成因、位置和形态进行分类，总计收集了6802张图像，并手动注释了2051张图片（一张图像可能包含多种缺陷）。该数据集旨在推动基于深度学习的PCB表面缺陷检测研究。

**2. 方法**

PCB4ZSAD 数据集完整信息
数据集名称：PCB4ZSAD
数据来源：缺陷图像来自实际生产的内层和外层PCB，通过自动光学检测（AOI）设备收集。
图像预处理：图像经过预处理，去除了噪声，并增强了对比度和亮度。
数据规模：
- 总图像数：6802 张
- 图像尺寸：226 × 226 像素
- 缺陷标注总数：2,051 个
- 缺陷类别：9 种
缺陷分类：基于缺陷的成因（铜残留、铜不足、导体刮痕、异物）进行分类，并进一步细分为9个类别：
| 类别 | 英文名称 | 缩写 |
|------|----------|------|
| 短路 | Short | SH |
| 毛刺 | Spur | SP |
| 残铜 | Spurious copper | SC |
| 断路 | Open | OP |
| 鼠咬 | Mouse bite | MB |
| 孔破 | Hole break | HB |
| 导体刮痕 | Conductor scratch | CS |
| 导体异物 | Conductor foreign object | CFO |
| 基材异物 | Base material foreign object | BMFO |
缺陷标记与数据集划分：利用 LabelImg 工具对每个缺陷进行手动边界标注，过滤掉无缺陷的图像、重复缺陷图像和不完整的缺陷图像。最终生成带缺陷标记的 2051 张图像。

**3.数据集的技术验证**

研究选用了AnomalyCLIP模型进行验证。使用默认参数配置进行训练和测试。验证结果显示，该模型在检测PCB表面缺陷时表现出色，图像级AUROC达到87.1%，图像级AP达到81.4%，像素级F1-max达到87%，像素级AUPRO达到30.2%，显示出该数据集对于深度学习模型的实用性和可靠性。

**4. 数据集的使用说明**

数据集提供了 COCO 格式（JSON 标注文件），存储了训练和验证数据的图像和标签文件。标签文件包含了缺陷的类别、边界框的坐标及其尺寸，这些数据可直接用于训练深度学习模型。
